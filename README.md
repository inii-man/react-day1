# ⚛️ React Playground - Belajar React untuk Pemula

Website interaktif untuk belajar React dari dasar. Cocok untuk pemula yang baru pertama kali masuk dunia React!

## 🎯 Fitur

- 📚 **Bahan Bacaan Lengkap** - Penjelasan konsep React yang mudah dipahami
- 💻 **Contoh Kode** - Setiap konsep dilengkapi dengan contoh kode yang jelas
- 🎮 **Playground Interaktif** - Coba langsung fitur-fitur React dengan demo live
- 🧩 **8 Topik Utama**:
  - 📚 Pengenalan React
  - ⚛️ JSX (JavaScript XML)
  - 🧩 Components
  - 📦 Props
  - 🔄 State
  - 🎯 Events
  - 🔀 Conditional Rendering
  - 📋 Lists & Keys

## 🚀 Cara Menjalankan

### Prerequisites

Pastikan Anda sudah menginstall:
- Node.js (versi 16 atau lebih baru)
- npm atau yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Jalankan development server:
```bash
npm run dev
```

3. Buka browser dan akses:
```
http://localhost:3000
```

## 🎓 Cara Menggunakan

1. **Mulai dari Pengenalan** - Baca section "Pengenalan" untuk memahami dasar React
2. **Ikuti Urutan** - Pelajari setiap topik secara berurutan
3. **Coba Sendiri** - Gunakan playground di setiap section untuk bereksperimen
4. **Modifikasi Kode** - Coba ubah contoh kode untuk memahami lebih dalam
5. **Praktikkan** - Buat proyek kecil sendiri setelah memahami setiap konsep

## 💡 Tips Belajar

- Jangan terburu-buru! Pahami setiap konsep sebelum lanjut
- Coba modifikasi setiap contoh yang diberikan
- Baca kode dengan teliti dan pahami alur eksekusinya
- Praktikkan dengan membuat proyek kecil sendiri
- Jangan takut membuat kesalahan - itu bagian dari belajar!
